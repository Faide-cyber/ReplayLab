# 无名杀复盘工具拓展（ReplayLab）

#### [English Doc](#)

### 1. 项目概述

**ReplayLab（复盘工具）** 是一个运行在**无名杀**（三国杀单机引擎）里的扩展，专门为「势孙綝」这类**极度依赖手牌排序与出牌顺序**的武将做的实验台。它把当前局面**整存整取**——手牌、装备、判定、体力、上限、铁索、翻面、标记、技能状态、每回合限一次计数、牌堆顺序——全部打包成一份快照，试完之后一键**原样还原**，换个排序再打一遍，最后并排对比两次尝试的差异。

核心要解决的问题只有一个：**同一手牌，不同排序，结果差多少？**

传统做法是每试一次就重开一局、重新摆牌，代价极高且难以复现。ReplayLab 让「记录起点 → 打一遍 → 保存记录 → 回到起点 → 换排序再打一遍 → 对比」变成十几秒的事，并且**牌堆连顺序带张数完全复原**，所以「摸到哪张」也能量化比较。

### 2. 系统架构与功能特点

#### 2.1 核心功能

- **起点快照 / 一键回滚**：整存整取局面，还原时牌堆、弃牌堆、处理区顺序一致；阵亡的人会复活；休整 / 移出游戏状态也回原样。
- **多次尝试并行对比**（本工具的「多模型」就是「多次尝试」）：所有记录默认全选，直接进对比表，多条记录不会错行。
- **手牌自定义**：按牌名加牌（中文 / 英文 id / 带花色点数），支持**虚拟牌**与**从牌堆定向检索**两种模式；点牌删除、清空、摸 1 张、一键回到起点手牌。
- **统计区间**：伤害（手牌伤害 / 技能伤害 / 按目标 / 按来源 / 属性 / 逆固加成）、过牌（获得 / 失去 / 弃置）、体力变化（起点的每人对比）、出牌顺序串。
- **敌我分色**：敌方红、友方绿、身份未明黄、自己白；统计口径含「对敌 / 对友 / 身份未明 / 自己承受」四个分列与合计校验行。
- **拆顺明牌**：本体选对方手牌时默认是牌背且顺序随机，打开后按真实牌面列出，回溯后才能牵到同一张。
- **牌堆分类浮标**：一行读出牌堆构成（己基 / 敌基 / 己锦 / 敌锦 / 锦其 / 装备 / 废牌）。

#### 2.2 工程约束

- 扩展的 `content` / `filter` 会被本体 `new Function` **重建**，闭包变量全部失效 → 钩子只能写一行转发到 `window.hfTool`，并全程 `try/catch`，工具出错不得影响游戏本体。
- 阶段钩子只能使用本体**真实存在**的事件名（`phaseUseBegin` / `phaseUseEnd` / `phaseDiscardBegin` …）；写成 `phaseUse` 等不存在的名字会**静默不触发**。
- 牌的 id 是英文（`sha` / `tao` / `tiesuo`），中文牌名需先经 `lib.translate` 反查。
- 本体 `game.updatez()` 会给 `<body>` 加 `transform: scale()`，自浮层一律挂 `document.documentElement`。

### 3. 环境要求与依赖

**运行环境**

- 「琉璃版无名杀」整合包（Electron 应用，包内无名杀本体 1.9.0）或任何可加载扩展的无名杀本体。
- 支持 WebView 的桌面 / 移动端；扩展目录可写。
- 可选：`localStorage`（记住开关与浮层位置）。

**开发环境**

- Node.js、支持 UTF-8 的编辑器。

### 4. 安装与部署

#### 4.1 安装扩展

1. 把 `复盘工具/` 整个目录放入无名杀扩展目录`extension`下。各版本无名杀对应目录不同，请自行查阅。
2. 启动游戏 → **扩展管理** → 勾选启用「复盘工具」。
3. **开始对局**，出现蓝色水波球即加载成功。

无名杀只在开局 / 加载扩展时读取代码，**改完必须重启游戏**（或重载扩展）才生效。

#### 4.2 配置

- 起点页六个开关（首次安装默认关）：**牌堆分类 / 拆顺明牌 / 自动快照 / 气泡常驻 / 结束提示 / 默认命名**。
- 手牌加牌方式：**虚拟牌（不进牌堆）/ 从牌堆取（定向检索）**。
- 开关与浮层位置写入 `localStorage`：`hf_cfg` / `hf_btn_pos` / `hf_panel_pos` / `hf_pilebar_pos`。

### 5. 使用流程

1. **记录起点**：自己的出牌阶段点【记录】；或先在起点页打开【自动快照】，每个出牌阶段自动存一份（手动起点优先）。
2. **正常出牌**：工具自动记录伤害、过牌、体力变化与出牌顺序等。
3. **存记录并回滚**：点【重来】＝ 存一条记录并回到起点；点【结束】＝ 存一条记录并跳到「记录」页。
4. **对比与导出**：记录页对比表**默认全选所有记录**，可支持记录导出。
